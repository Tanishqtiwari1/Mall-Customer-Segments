    How is this calculated?

    The customer is scaled the same way as the training data. We then measure the distance d to each segment centre in standard-deviation units. K-Means picks the nearest centre. The probabilities treat each segment as a bell curve with the spread observed in the data (soft K-Means), so closer centres get exponentially more weight.
